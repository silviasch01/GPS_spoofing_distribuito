# Cooperative / Networked / Swarm-based GNSS spoofing detection (consistency of GNSS fixes vs. inter-platform relative measurements)

Scope: civilian GNSS, 2011–2026. Each method entry records (a) what is exchanged/compared, (b) test statistic and decision rule, (c) attacker model, (d) assumptions, (e) reported performance, (f) bibliographic data, and (g) RELATIVE-ONLY vs ABSOLUTE-ANCHOR dependence. Fields I could not verify from a primary source in this session are marked "unverified". Formulas in plain text / LaTeX-like notation.

Working taxonomy used below (my own, for the thesis chapter):
- Class R (relative-only): the test is a function only of {GNSS_i − GNSS_j} and of inter-platform measurements {d_ij}; invariant under z_i -> z_i + c for a common c (a rigid translation of all fixes is invisible).
- Class A (absolute anchor): the test uses at least one quantity tied to an external frame (fixed ground sensors/anchors, map, cellular/terrestrial ranging, encrypted-signal correlation with a reference station).
- Class S (signal-domain cross-check): peers exchange raw signal snippets or pseudorange/clock quantities rather than positions; a common position translation may or may not be visible depending on what is correlated.

## Key question 1 — Heng, Work, Gao, "GPS Signal Authentication From Cooperative Peers" (IEEE T-ITS 2015): what is cross-checked, does it need an unspoofed peer?

### Takeaway
It is a Class S signal-domain scheme, not a geometric relative-distance check: the user receiver cross-correlates snippets of the (unknown, encrypted) military P(Y) code — which it cannot generate itself but which is present in quadrature with C/A — against snippets recorded by one or more "cross-check" peer receivers; a civil spoofer cannot synthesize P(Y), so the correlation peak disappears under spoofing. Peers are explicitly modelled as UNRELIABLE (possibly themselves spoofed), no single trusted/unspoofed peer is required, and the aggregate error probabilities decay exponentially with the number N of peers provided the per-peer reliability margin is positive.

### Cited Findings
- Bibliographic data: Liang Heng, Daniel B. Work, Grace Xingxin Gao, "GPS Signal Authentication From Cooperative Peers", IEEE Transactions on Intelligent Transportation Systems, vol. 16, no. 4, pp. 1794–1805, Aug. 2015, DOI 10.1109/TITS.2014.2372000 (IEEE article no. 6985623). No open-access PDF listed by Semantic Scholar (status CLOSED). — [Semantic Scholar record](https://api.semanticscholar.org/graph/v1/paper/DOI:10.1109/TITS.2014.2372000?fields=title,abstract,authors,year,venue,externalIds,openAccessPdf); [Illinois Experts record](https://experts.illinois.edu/en/publications/gps-signal-authentication-from-cooperative-peers-2/); [Peeref](https://peeref.com/works/603140)
- Title discrepancy: NIST's reference list gives the title as "GNSS Signal Authentication from Cooperative Peers"; IEEE/Illinois records use "GPS". Use the IEEE form. — [NIST document](https://www.nist.gov/document/14gaogpssecuritypdf)
- Architecture (from G. Gao's SCPNT 2014 talk "Cooperative GPS Signal Authentication from Unreliable Peers", same research line): a two-step process, (1) pair-wise check — the user receiver sends a baseband snippet to N cross-check receivers, each computes a correlation and returns a binary decision; (2) decision aggregation at the user receiver. Stated design goals: "no need to change satellite transmission", "no need to have secure reference stations or communication links", "tolerate errors". Merits claimed: "network and geographical redundancy". — [Gao SCPNT 2014 slides (PDF)](https://web.stanford.edu/group/scpnt/pnt/PNT14/2014_Presentation_Files/15.SCPNT_Coop%20Authentication_Gao_2014.pdf)
- What is compared: the pair-wise check is a "cross-correlation of military P(Y) code" between the two receivers' quadrature-phase baseband snippets (building on Lo et al. 2009 and Psiaki/Humphreys et al. 2013). Ideal result: not spoofed -> a single correlation peak in the P(Y) quadrature channel; spoofed -> "no correlation peak", because the "spoofer cannot generate" P(Y). In the in-phase C/A channel the spoofed case shows 40 ms-spaced multiple peaks. — [Gao SCPNT 2014 slides](https://web.stanford.edu/group/scpnt/pnt/PNT14/2014_Presentation_Files/15.SCPNT_Coop%20Authentication_Gao_2014.pdf)
- Test statistic and decision rule (as visible in the slide excerpts that reproduce the paper's experiments): a pair-wise test statistic C "as defined in (3)" is compared with a threshold ζ; "The test statistic C is above the threshold ζ until the attack starts. As soon as the attack starts, C quickly drops below ζ." Experiments used a spoofer whose counterfeit C/A code phase moved away from the authentic phase at 0.375 and 0.5 chip/s. — [Gao SCPNT 2014 slides](https://web.stanford.edu/group/scpnt/pnt/PNT14/2014_Presentation_Files/15.SCPNT_Coop%20Authentication_Gao_2014.pdf)
- Peer reliability model: "Modeling unreliable cross-check receivers" — the cross-check receiver may be authentic, spoofed by a DIFFERENT spoofer (probability P_SD) or spoofed by the SAME spoofer (probability P_SS); per-pair false alarm α and missed detection β. Aggregated figure of merit shown on the slides: P_FA = P_MD <= exp(−N γ^2), with γ = (1 − α − β)(1 − P_SD − ...) (expression truncated in the extracted text; the full form is in the paper, unverified here). I.e. both error probabilities decrease exponentially with the number N of peers. — [Gao SCPNT 2014 slides](https://web.stanford.edu/group/scpnt/pnt/PNT14/2014_Presentation_Files/15.SCPNT_Coop%20Authentication_Gao_2014.pdf)
- Reported performance (slides): pair-wise P_MD vs P_FA curves for snippet lengths T = 1e5 … 1e6 samples; receivers 3000 km apart (San Francisco – Champaign, static, one in urban canyon, C/N0 = 47 dB-Hz) and 22 km apart (Rantoul – Champaign, one moving at ~45 mph, C/N0 = 51 dB-Hz); "near ideal correlation" at 22 km, "some residual correlation" at 3000 km, spoofing detectable in both. Hardware: SiGe sampler front ends, 2-bit quantisation, 2.72 MHz bandwidth. — [Gao SCPNT 2014 slides](https://web.stanford.edu/group/scpnt/pnt/PNT14/2014_Presentation_Files/15.SCPNT_Coop%20Authentication_Gao_2014.pdf)
- Secondary summary (web search of IEEE record): the paper "describes a receiver that compares its encrypted military P(Y) signal with signals from other receivers to detect spoofing" and "detection performance improves exponentially as cross-check receivers are added". — [Peeref](https://peeref.com/works/603140); [Inside GNSS, "Cooperative GNSS Authentication"](https://insidegnss.com/cooperative-gnss-authentication/)
- Related earlier publication by the same group: Inside GNSS 2013 article "Cooperative GNSS authentication reliability from unreliable peers" (magazine article, distinct from the T-ITS paper). — [Inside GNSS](https://insidegnss.com/?p=22416)

### Inferences
- Does it need an unspoofed peer? No single trusted peer is required; the scheme is designed for a crowd of unreliable peers and tolerates a fraction of spoofed peers. However the aggregate bound only works if the "reliability margin" γ > 0, i.e. the majority of peers must effectively be authentic or spoofed by a different spoofer than the user (a peer spoofed by the SAME spoofer sees the same counterfeit snippet and would falsely authenticate). So implicitly: not all peers may be under the same spoofer.
- Relative vs absolute: this test does not depend on positions at all; it checks the presence of the authentic P(Y) waveform. A rigid common translation of all fixes produced by a C/A-only generator spoofer is still DETECTED (the P(Y) component is missing), so the "common translation blind spot" of geometric relative checks does not apply. Conversely, a wideband meaconing/replay attack that re-broadcasts the full L1 band (P(Y) included) with a delay would preserve P(Y) correlation and is outside what this test can catch (unverified whether the paper discusses this explicitly).
- Classification: Class S (signal cross-check); no absolute anchor needed, but peers must receive the SAME satellites at overlapping times (common visibility), and the communication link carries baseband snippets (bandwidth cost, not positions).

### Gaps
- The full text (equation (3) for C, exact threshold setting, full expression for γ, and the paper's own numerical P_FA/P_MD tables) could not be opened (IEEE paywall); the SCPNT slides are the primary-author source used. The abstract itself was elided by the publisher in the Semantic Scholar record.

## Key question 2 — Bhamidipati & Gao, multi-receiver direct time estimation and spoofer localization (ION GNSS+ 2017; IEEE TAES 2019): which geometry is used?

### Takeaway
The TAES version exists: "GPS Multireceiver Joint Direct Time Estimation and Spoofer Localization", IEEE TAES 55(4):1907–1919, 2019, DOI 10.1109/TAES.2018.2879532. The geometry is a set of static receivers at KNOWN surveyed positions inside a power substation (networked PMU timing scenario); a joint direct-time-estimation of the common GPS time across receivers plus a cross-receiver signal-similarity test detects spoofing, and a particle-filter/Kalman-filter stage localises the spoofer from the receivers' geometric diversity. Because receiver positions are known a priori, this is an ABSOLUTE-anchor scheme (Class A).

### Cited Findings
- Journal citation (verified via Crossref and Semantic Scholar): Sriramya Bhamidipati, Grace Xingxin Gao, "GPS Multireceiver Joint Direct Time Estimation and Spoofer Localization", IEEE Transactions on Aerospace and Electronic Systems, vol. 55, no. 4, pp. 1907–1919, 2019, DOI 10.1109/TAES.2018.2879532. No OA PDF listed (CLOSED). — [Crossref query](https://api.crossref.org/works?query.bibliographic=Bhamidipati+Gao+spoofer+localization+multi-receiver+direct+time+estimation&rows=6); [Semantic Scholar](https://api.semanticscholar.org/graph/v1/paper/DOI:10.1109/TAES.2018.2879532?fields=title,abstract,authors,year,venue,externalIds,openAccessPdf)
- Conference versions: S. Bhamidipati, G. X. Gao, "GPS Spoofer Localization for PMUs using Multi-Receiver Direct Time Estimation", Proc. ION GNSS+ 2017, pp. 2780–2784, DOI 10.33012/2017.15333; S. Bhamidipati, Y. Ng, G. X. Gao, "Multi-receiver GPS Based Direct Time Estimation for PMUs", Proc. ION GNSS+ 2016, pp. 833–837, DOI 10.33012/2016.14682. — [Crossref query](https://api.crossref.org/works?query.bibliographic=Bhamidipati+Gao+spoofer+localization+multi-receiver+direct+time+estimation&rows=6); Illinois manuscript PDF of the 2017 paper: [ws.engr.illinois.edu](https://ws.engr.illinois.edu/sitemanager/getfile.asp?id=2304)
- Method (TAES abstract, paraphrased by the fetch tool): jointly estimates the spoofer location and GPS time using "several static receivers placed at known positions within a power substation"; identifies likely clock parameters (direct time estimation = maximum-likelihood search over clock bias/drift candidates directly on correlator outputs), "compares signal similarity across receivers to detect spoofing", and uses "a combined particle and Kalman filter to localize the spoofer"; derives detection and false-alarm probabilities and a Cramér–Rao lower bound for localisation accuracy; validated on authentic open-sky GPS signals with simulated spoofing; results: accurate spoofer localisation and time estimates within the accuracy required by IEEE C37.118 (synchrophasor standard, ±1 µs / 26.5 µs TVE-related bound). — [Semantic Scholar](https://api.semanticscholar.org/graph/v1/paper/DOI:10.1109/TAES.2018.2879532?fields=title,abstract,authors,year,venue,externalIds,openAccessPdf)
- The ION 2017 abstract states the localisation "uses the geometrical diversity of multiple receivers" and the experiments use a "replayed meaconing attack". — [search summary of Illinois PDF](https://ws.engr.illinois.edu/sitemanager/getfile.asp?id=2304)
- Follow-up networked-PMU work (same authors): S. Bhamidipati, G. X. Gao, "GPS Spoofing Mitigation and Timing Risk Analysis in Networked PMUs via Stochastic Reachability", arXiv:2101.04835 (Jan 2021; journal version unverified). Proposes SR-DKF (Stochastic-Reachability-based Distributed Kalman Filter) estimating GPS time across a receiver network together with a probabilistic zonotope (p-Zonotope) reachable set; two tiers: (i) measurement-level spoofing flag when innovations fall outside the expected p-Zonotope; (ii) state-level timing-risk = probability that the p-Zonotope intersects the unsafe set violating IEEE C37.118.1a-2014. Evaluated in simulation under "coordinated signal-level spoofing" of the receiver network; timing-risk estimate robust to number of receivers. — [arXiv 2101.04835](https://arxiv.org/abs/2101.04835)

### Inferences
- Geometry: static receivers with KNOWN relative and absolute positions (substation footprint, tens of metres), so the expected inter-receiver pseudorange/time differences for each satellite are deterministic. A single terrestrial spoofer injects a common signal whose arrival-time differences between receivers are governed by the spoofer-to-receiver geometry rather than the satellite geometry; this mismatch is what both detects spoofing and makes the spoofer localisable (TDOA-like inversion). Because the known positions are absolute (surveyed), the scheme is Class A; a spoofer imposing a common clock offset to all receivers would be detected only insofar as its terrestrial geometry breaks the expected inter-receiver signal-similarity pattern, not by a position-consistency test.
- The 2021 SR-DKF work is the closest in this family to a "coordinated attacker spoofing all members consistently" model (coordinated signal-level spoofing), but detection relies on innovation bounds (temporal consistency), not on relative geometry.

### Gaps
- The exact test statistic form (signal-similarity metric, thresholds, P_D/P_FA numbers, CRLB values, localisation error in metres) from the TAES full text could not be accessed.

## Key question 3 — Jansen et al., Crowd-GPS-Sec (IEEE S&P 2018): what is the invariant?

### Takeaway
Crowd-GPS-Sec uses the existing crowd of ground ADS-B receivers (OpenSky Network) as fixed, independent witnesses: an aircraft's GPS-derived position, self-reported via ADS-B, must be consistent with the position implied by the time-differences-of-arrival (TDOA / multilateration) of its ADS-B transmissions at the sensors, and with nearby aircraft; the ground sensors are fixed infrastructure with known positions, so this is a Class A (absolute-anchor) scheme — a common translation of all aircraft fixes is detectable because the witnesses are not translated.

### Cited Findings
- Bibliographic data: Kai Jansen, Matthias Schäfer, Daniel Moser, Vincent Lenders, Christina Pöpper, Jens B. Schmitt, "Crowd-GPS-Sec: Leveraging Crowdsourcing to Detect and Localize GPS Spoofing Attacks", 2018 IEEE Symposium on Security and Privacy (SP), San Francisco, pp. 1018–1031, DOI 10.1109/SP.2018.00012 (IEEE Xplore document 8418651). OA PDF listed by Semantic Scholar at ieeexplore.ieee.org/ielx7/8418581/8418583/08418651.pdf (download returned an HTML page in this session, so treat as "listed, not verified"). — [Semantic Scholar record](https://api.semanticscholar.org/graph/v1/paper/DOI:10.1109/SP.2018.00012); [RPTU repository](https://biblio.ub.rptu.de/frontdoor/index/index/year/2024/docId/12133); [ETH Research Collection](https://www.research-collection.ethz.ch/entities/publication/51b11a19-0d51-4d18-8637-e34042866350)
- System description (Ruhr-Universität Bochum press release): monitors the position signals aircraft and drones broadcast for air traffic control; "detects interfering signals within a maximum of two seconds" and "can locate the attacker in less than 15 minutes, to a precision of 150 meters"; relies on crowdsourced sensors (OpenSky Network); "no new monitoring infrastructure is required" and aircraft/drone GPS receivers need not be modified. — [RUB news](https://news.rub.de/node/3658)
- Method components as summarised by a secondary reading note: (1) multilateration from time differences of arrival at the crowd sensors, (2) time alignment of transmissions, (3) cross-check of the MLAT-derived position against the position the aircraft reports (test 1), plus a comparison among nearby aircraft (test 2). (Secondary source; consistent with the press release and with the authors' later work.) — [zybuluo reading note (secondary)](https://zybuluo.com/EggGump/note/1393714)
- OpenSky background: the crowd has >3000 registered sensors; most low-cost sensors are not time-synchronised or calibrated, which makes timing-based checks harder (the Crowd-GPS-Sec/OpenSky line of work addresses this with nanosecond-precision ToA estimation and sensor clock alignment). — [Nanosecond-precision ToA, arXiv 1802.07016](https://arxiv.org/pdf/1802.07016)
- Follow-up by overlapping authors (do NOT conflate): K. Jansen, L. Niu, N. Xue, I. Martinovic, C. Pöpper, "Trust the Crowd: Wireless Witnessing to Detect Attacks on ADS-B-Based Air-Traffic Surveillance", NDSS 2021 (DOI unverified). Four verification tests: (i) sanity, (ii) differential, (iii) dependency (position must be reachable from the previous one, tolerance up to 100 m), (iv) "cross check" of the message RECEPTION PATTERN (which sensors did/did not receive a report, binary feature vector over sensors, decision-tree ML trained on 132,883,464 recorded ADS-B reports) against the pattern expected for the claimed position. Works "if at least three sensors observe the same airspace"; attack classes: GPS spoofing, ADS-B spoofing (single sensor / multiple / all sensors in a region), sensor-control/Sybil; "detection rates beyond 95 % for moderate GPS spoofing deviations and any form of ADS-B spoofing", false-positive rate 0 % after time-windowing with threshold set to the lowest score observed under normal operation. — [NDSS 2021 paper PDF](https://www.ndss-symposium.org/wp-content/uploads/2021-552-paper.pdf)
- Earlier multi-receiver (non-crowd) root of this line: K. Jansen, N. O. Tippenhauer, C. Pöpper, "Multi-Receiver GPS Spoofing Detection: Error Models and Realization", Proc. ACSAC 2016, pp. 237–250 (DOI 10.1145/2991079.2991092, unverified in this session): compares the FIXED known distance between co-mounted receivers with the distance between their reported positions; under single-transmitter spoofing the reported positions collapse to (nearly) the same point. Reported detection rate quoted by Mykytyn et al.: 99 %. — [Park & Yoo 2026 reference list](https://arxiv.org/html/2608.06885); [Mykytyn et al. 2023, Sec. III](https://arxiv.org/pdf/2301.12766)

### Inferences
- The invariant in Crowd-GPS-Sec is: for a genuine transmitter at claimed position p, the arrival-time differences at fixed sensors s_k, s_l must satisfy (|p − s_k| − |p − s_l|)/c = t_k − t_l (within clock/ToA error); equivalently the MLAT solution p_MLAT must agree with the ADS-B/GPS-reported p_GPS. A spoofed aircraft reports p_GPS displaced while its RF emission point (hence the TDOA pattern) is unchanged, so |p_MLAT − p_GPS| exceeds the threshold. Localisation of the spoofer exploits that all victims in the spoofer's footprint report positions consistent with a common false clock/position, i.e. correlated offsets across aircraft (test 2, "nearby aircraft comparison").
- Attacker model: a terrestrial spoofer affecting one or many aircraft; the method tolerates many spoofed victims because the witnesses are the ground sensors, not the aircraft. Trust assumptions: enough honest sensors in view (the 2021 paper formalises ">= 3 benign sensors" and adds Sybil resistance).
- Relative vs absolute: Class A. The ground sensors are the absolute anchor; a coordinated attacker that translates ALL aircraft fixes by the same vector would still be caught, since the sensors' positions do not move. (The ACSAC 2016 scheme, by contrast, is Class R: it only checks the fixed inter-receiver distance.)

### Gaps
- Exact test statistic/threshold of Crowd-GPS-Sec (e.g. distance threshold between MLAT and reported position, number of sensors required, clock-synchronisation model) not retrieved: the OA PDF and author copies were not reachable (404/403/HTML). The "2 s / 15 min / 150 m" figures come from the press release, not verified against the paper text.

## Key question 4 — UAV-swarm spoofing detection papers (2018–2026): citation and exact consistency test

### Takeaway
Six concrete swarm papers were located with full or near-full bibliographic data. All the practical detectors (Mykytyn 2023; Meng 2023; Bi 2024; Michieletto 2023; Zhong 2026; Eldosouky 2020) compare GNSS-derived inter-UAV geometry with an independent relative measurement (UWB range, cooperative-positioning range, neighbour proximity) and therefore are Class R (relative-only), with the exception of Michieletto et al. which also fuses inertial data (temporal, still not absolute). The 2026 Park & Yoo preprint is the first to state formally that such detectors are blind to a common translation and to propose an absolute-anchor remedy.

### Cited Findings

**[S1] Mykytyn, Brzozowski, Dyka, Langendoerfer 2023 — GPS-vs-IR-UWB distance check (Class R)**
- Citation: Pavlo Mykytyn, Marcin Brzozowski, Zoya Dyka, Peter Langendoerfer, "GPS-Spoofing Attack Detection Mechanism for UAV Swarms", 2023 12th Mediterranean Conference on Embedded Computing (MECO), Budva, Montenegro, June 2023; IEEE Xplore document 10154998 (DOI 10.1109/MECO58584.2023.10154998 — unverified; pages unverified). Author version: arXiv:2301.12766. Affiliations: IHP Leibniz-Institut für innovative Mikroelektronik and BTU Cottbus-Senftenberg. — [arXiv PDF](https://arxiv.org/pdf/2301.12766)
- (a) Exchanged/compared: each UAV reports its GPS (lat, lon, alt) to the ground control station (GCS); GCS also requests IR-UWB two-way-ranging distances between UAV_1 and every other UAV (measurements "taken regularly for collision avoidance purposes anyway"). GCS computes d_GPS(UAV_1, UAV_i) via the spherical law of cosines, d = R·arccos(sin φ1 sin φi + cos φ1 cos φi cos Δλ), R = 6371 km, corrected for altitude difference by Pythagoras, and compares it with d_UWB(UAV_1, UAV_i). — [arXiv PDF, Sec. IV](https://arxiv.org/pdf/2301.12766)
- (b) Test statistic / rule (Table II): spoofing declared if |d_GPS(1,i) − d_UWB(1,i)| > d_thr, with d_thr set from the error budget "GPS localization error not larger than 4.9 m [GPS.gov] and IR-UWB ranging error within 30 cm", i.e. difference should not exceed the sum of the two errors (d_thr ≈ 5.2 m; with RTK/DGPS at 1–3 cm the threshold "can be reduced significantly"). Second criterion: GPS(UAV_1) ≅ GPS(UAV_i) (reported coordinates identical, d_GPS ≈ 0) flags the case where several UAVs receive the SAME spoofed signal; note d_UWB cannot be ≈ 0 (that would be a collision). — [arXiv PDF, Sec. IV-A](https://arxiv.org/pdf/2301.12766)
- (c) Attacker model: single-transmitter (one UAV affected, or ≥ 2 UAVs receiving identical signal) and multi-transmitter (same signal from several transmitters = broader area; or different signals per transmitter). Explicit statement on the coordinated attacker: "To render our detection mechanism ineffective, an attacker would need to simultaneously spoof each GPS receiver of every drone in the swarm with an individual GPS [signal] ... [consistent] to the real-time distance between them, which is virtually impossible and very resource demanding." — [arXiv PDF, Sec. IV](https://arxiv.org/pdf/2301.12766)
- (d) Assumptions: centralised processing at GCS; UWB (Decawave DW1000, DS-TWR, ~cm precision, ≤150 m range) available for collision avoidance; telemetry link ~40 kbps; swarm of up to ~20 UAVs; trusted UWB and trusted telemetry (not discussed). Energy overhead estimated: 3.55 mJ per ranging, 2 Hz ranging + reporting → <1 s flight-time loss per 25-min flight. — [arXiv PDF, Sec. IV-B](https://arxiv.org/pdf/2301.12766)
- (e) Performance: none — "this is the initial stage of this study ... Performance, detection and false positive rates will be presented in the next stages". — [arXiv PDF, Sec. V](https://arxiv.org/pdf/2301.12766)
- (g) Relative-only: yes (only d_GPS(i,j) and d_UWB(i,j)); a rigid common translation preserving all pairwise distances is invisible (confirmed by Park & Yoo 2026, who evaluate exactly this detector, AUC ≈ 0.5 under RigidShift). — [Park & Yoo 2026](https://arxiv.org/html/2608.06885)

**[S2] Meng, Zhang, Yang, Yang 2023 — GPS-adaptive spoofing detection via cluster cooperative positioning (Class R, details partly unverified)**
- Citation: Lianxiao Meng, Long Zhang, Lin Yang, Wu Yang, "A GPS-Adaptive Spoofing Detection Method for the Small UAV Cluster", Drones, vol. 7, no. 7, art. 461, 2023, DOI 10.3390/drones7070461 (open access at mdpi.com/2504-446X/7/7/461). — [Crossref query](https://api.crossref.org/works?query.bibliographic=Eldosouky+Drones+in+Distress+game-theoretic+countermeasure+GPS+spoofing+UAV&rows=3); [MDPI page](https://www.mdpi.com/2504-446X/7/7/461)
- (a)–(c): abstract-level only: an "adaptive spoofing detection (ASD) method based on UAV cluster cooperative positioning" with two mechanisms — a "GPS spoofing signal detection (SSD) mechanism based on cluster cooperative positioning" (started when the cluster enters task state) and a "relative security machine optimal marking (RSOM) mechanism" triggered "when there is more than one spoofing source and more than one UAV is attacked by different sources". Claimed "lightweight calculation level, strong applicability, and high real-time performance"; "one mechanism detects spoofing from a single source, the other handles multiple spoofing sources". — [search summary of MDPI abstract](https://www.mdpi.com/2504-446X/7/7/461)
- (d),(e): equations, ranging sensor, thresholds and numerical results NOT retrieved (MDPI returned 403/503 in this session) — unverified.
- (g): based on cooperative positioning (relative ranges between cluster members), hence Class R by construction; whether an absolute reference is used is unverified.

**[S3] Bi, Li, Hu, Ni, Wang, Wang 2024 — SDP feasibility of reported positions vs pairwise distances (Class R)**
- Citation: Siguo Bi, Kai Li, Shuyan Hu, Wei Ni, Cong Wang, Xin Wang, "Detection and Mitigation of Position Spoofing Attacks on Cooperative UAV Swarm Formations", IEEE Transactions on Information Forensics and Security, vol. 19, 2024 (pages/DOI unverified; accepted Dec 2023), preprint arXiv:2312.03787. — [arXiv abs](https://arxiv.org/abs/2312.03787); [Park & Yoo reference list](https://arxiv.org/html/2608.06885)
- (a) Exchanged: individually reported UAV positions and pairwise inter-UAV distance measurements. (b) Test: "malicious-UAV detection cast as a localization feasibility problem" — if reported positions and measured distances cannot be jointly consistent, the reporting UAVs are suspect; the non-convex feasibility problem is relaxed via semidefinite relaxation into an SDP; two algorithms exploit the proximity of neighbouring UAVs to identify WHICH UAVs are malicious; mitigation stage follows. (c) Attack types: "distributed, collusion, and mixed" (colluding spoofed nodes explicitly considered). (d) Simulation only, various swarm topologies. (e) Detection success rate improved by up to 65 % (distributed), 55 % (collusion), 51 % (mixed) over benchmarks. — [arXiv abs](https://arxiv.org/abs/2312.03787)
- (g) Relative-only: Park & Yoo score it by a reported-position/range feasibility residual and show it blind to RigidShift (AUC 0.54/0.49/0.48 at 2/5/20 cm/s; exact cvxpy SDP flagged the covert ramp on 1 of 60 runs). — [Park & Yoo 2026](https://arxiv.org/html/2608.06885)

**[S4] Michieletto, Formaggio, Cenedese, Tomasin 2023 — information-theoretic consistency of GNSS, inter-UAV ranging and IMU (Class R + temporal)**
- Citation: Giulia Michieletto, Francesco Formaggio, Angelo Cenedese, Stefano Tomasin, "Robust Localization for Secure Navigation of UAV Formations Under GNSS Spoofing Attack", IEEE Transactions on Automation Science and Engineering, vol. 20, no. 4, pp. 2383–2396, Oct. 2023, DOI 10.1109/TASE.2022.3208662 (no OA PDF listed). — [Crossref](https://api.crossref.org/works?query.bibliographic=Robust+Localization+for+Secure+Navigation+of+UAV+Formations+Under+GNSS+Spoofing+Attack&rows=3); [Semantic Scholar](https://api.semanticscholar.org/graph/v1/paper/DOI:10.1109/TASE.2022.3208662)
- (a) Measurements: inertial sensors, inter-UAV relative ranging, GNSS; distributed cooperative procedure with two cascaded estimation stages: (i) spoofing detection, (ii) localisation under attack. (b) Detection stage "applies information-theoretic tools to form a practical threshold test that checks whether the multimodal measurements are mutually consistent" (exact statistic — e.g. KL-divergence / GLRT form — unverified); localisation stage weights each source by measured reliability. (c) Attacker: GNSS spoofing altering navigation signals "for map counterfeiting or hijacking" (number of spoofed UAVs unverified). **[S7] Park & Yoo 2026 — Rigid-covert spoofing: blind spot of relative detectors, absolute-anchor defence (Class A proposed)**
- Citation: Minseok Park, Joon Soo Yoo, "Rigid-Covert GNSS Spoofing of UAV Swarms: A Structural Blind Spot, Its Detection Limit, and Absolute-Anchor Defenses", arXiv:2608.06885 (cs.CR, cs.RO), submitted 7 Aug 2026, 15 pp., simulation-based; not peer-reviewed as of this note. — [arXiv abs](https://arxiv.org/abs/2608.06885)
- Attack model "RigidShift": a common, slowly varying translation b(t) (ramp rate v in cm/s) applied to all drones' GNSS positions. Proposition 1: any detector depending only on {z_i − z_j} and {d_ij} is invariant under z_i ↦ z_i + c for common c ∈ R², "so a common-mode offset b(t) cannot be observed from relative channels alone" ("gauge-freedom argument"). — [arXiv HTML](https://arxiv.org/html/2608.06885)
- Detectors formalised: distance verification (Mykytyn et al.): score = max_{(i,j)} | ||z_i − z_j|| − d_ij |, flag if > θ; cooperative SDP (Bi et al.): feasibility residual; proposed over-determined-geometry detector: median_i ||z_i − x̂_i|| with X̂ = MDS({d_ij}) rigidly aligned to anchors; proposed absolute-anchor residual: median over anchored drones of ||z_i − a_i|| (a_i = trusted absolute position of anchor drone i); all detectors gated on ≥ 3 consecutive frames; thresholds at the 5 % false-alarm quantile of 120 no-attack runs. — [arXiv HTML](https://arxiv.org/html/2608.06885)
- Results (AUC, 200 seeds, ramp 2 / 5 / 20 cm/s): distance verification 0.56 / 0.49 / 0.48; cooperative SDP proxy 0.54 / 0.49 / 0.48; over-determined geometry 0.84 / 1.00 / 1.00; absolute anchor 0.73 / 1.00 / 1.00; exact cvxpy SDP flagged the covert ramp on 1/60 attack runs (1.7 %). Detection floor for a calibrated anchor-residual detector under anchor drift γ: v* = 2γ/(1 − t_s/T) (+ noise term); recovery pipeline reconstructs geometry from inter-drone ranges, aligns to a trusted anchor subset with Byzantine-robust fitting, median error 0.39 m under ~10.1 m GNSS drift; limits: non-collinear anchors, anchor coverage, drift/attack aliasing as τ→0, majority anchor compromise. Also notes "at metre-scale spacing the induced differential displacement is millimetric, so relative checks stay at their false-alarm floor" and that a single spoofer can preserve the formation exactly for N ≤ 9 (citing Chen et al. 2025). — [arXiv HTML](https://arxiv.org/html/2608.06885); [search summary](https://arxiv.org/pdf/2608.06885)

**Supporting attack-side papers that define the coordinated-attacker threat for swarms**
- Wenxin Chen, Yingfei Dong, Zhenhai Duan, "Impacts of a Single GPS Spoofer on Multiple Receivers: Formal Analysis and Experimental Evaluation", 2024 IEEE 21st Consumer Communications & Networking Conference (CCNC), pp. 127–134, DOI 10.1109/CCNC51664.2024.10454872. - Christopher Tibaldo, Harshad Sathaye, Giovanni Camurati, Srdjan Capkun, "GNSS-WASP: GNSS Wide Area SPoofing", USENIX Security 2025 (pre-publication PDF; pages/DOI unverified). A constellation of synchronised transmitters, one per impersonated satellite, spoofs all receivers in an area "while preserving their true formation (i.e., their relative distances)" without tracking victims; "bypasses state-of-the-art spoofing countermeasures that rely on constellations of receivers with known distances" (Jansen et al. 2016 [34], Tippenhauer et al. 2011 [62]) and on movement consistency. Sec. 4.3 experiment: four Raspberry-Pi u-blox MAX-M8Q receivers on a rooftop, reference point 10/250/500/1000 m away, 5-min traces: "the relative distances across receivers remain consistent, preventing detection with classic multi-receiver countermeasures". Sec. 5 ("WASP-aware countermeasures"): these countermeasures "work under the assumption that practical attacks (e.g., single transmitter) cause large inconsistencies ... In their original form, they are ineffective at detecting GNSS-WASP within the 3D area where consistency is preserved"; detection then has to exploit the residual deterministic approximation error Δd_i with widely spaced receiver arrays. Reported: two receivers spoofed while maintaining relative distance with average error 0.97 m. — [USENIX pre-pub PDF](https://www.usenix.org/system/files/conference/usenixsecurity25/sec25cycle1-prepub-757-tibaldo.pdf)
- Foundational requirement analysis: Nils Ole Tippenhauer, Christina Pöpper, Kasper Bonne Rasmussen, Srdjan Capkun, "On the Requirements for Successful GPS Spoofing Attacks", Proc. 18th ACM CCS, 2011 (pages 75–86, DOI 10.1145/2046707.2046719 — unverified): with a single antenna, spoofing a group of receivers to arbitrary positions while preserving their mutual distances is only possible for specific geometries; motivates multi-receiver consistency checks. — [cited in GNSS-WASP ref [62]](https://www.usenix.org/system/files/conference/usenixsecurity25/sec25cycle1-prepub-757-tibaldo.pdf)

### Inferences
- Common structure of the swarm detectors: residual r_ij = ||p_i^GNSS − p_j^GNSS|| − d_ij^{UWB} compared with a threshold derived from the GNSS + ranging error budget (Mykytyn: ~5.2 m with SPS, cm-level with RTK); SDP/MDS variants generalise this to the joint feasibility of all N(N−1)/2 residuals. All are invariant under common translation, and (for distance-only ranging) also under common rotation/reflection of the whole swarm — the full Euclidean group E(2)/E(3) — because pairwise distances are invariant to rigid motions, not just translations (the SDP/MDS formulations inherit the same gauge freedom).
- The "identical coordinates" criterion (Mykytyn Case 2) catches a naive single-transmitter spoofer (Chen et al. 2024 prove all victims then read the same position) but not a transmitter constellation (GNSS-WASP) or an attacker who adds per-UAV offsets consistent with the real geometry.

### Gaps
- Could not retrieve the full method/equations of Meng et al. 2023 (Drones) and Zhong et al. 2026 (RESS) and the page/DOI numbers of Bi et al. 2024 (TIFS) and Mykytyn et al. 2023 (MECO); these are marked unverified. No experimental (flight-test) performance figures exist for any of the UWB-based swarm detectors found — all are simulation or design-stage.

## Key question 5 — Vehicle platoon / V2X cooperative spoofing detection (GNSS inter-vehicle distance vs radar/lidar/DSRC/CACC ranging)

### Takeaway
The reference line is Swaszek, Hartnett & Seals (ION ITM 2016 → ION GNSS+ 2017): a Neyman–Pearson GLRT that fuses GNSS fixes of the platoon with range-only inter-vehicle measurements, under the explicit assumption that the spoofer reaches only a subset ("nominally one") of the vehicles; the 2016 variant ranges to FIXED sites (Class A), the 2017 platoon variant is Class R. Carson et al. (IEEE IV 2016) use the CACC radar/DSRC ranging already on board; Kosmanos et al. (Electronics 2026) use DSRC-exchanged state and a decentralised Kalman residual + Mahalanobis test.

### Inferences
- For the platoon case, the single-victim assumption of Swaszek et al. is load-bearing: the GLRT's alternative hypothesis places an unknown offset on ONE vehicle's fix; if the same offset is added to all fixes, the GNSS-derived inter-vehicle ranges are unchanged and the likelihood ratio is 1 (relative-only). Swaszek's 2016 fixed-site variant does not have this limitation because the DME/altimeter range anchors the absolute position.
- CACC-based schemes (Carson et al.) have the practical advantage that forward radar gives the range to the preceding vehicle without extra hardware, but radar ranging is pairwise-sequential along the platoon; a consistent common offset again cancels.

- Full texts of Swaszek 2017, Carson 2016 and Kosmanos 2026 were not accessible; explicit test-statistic expressions and numerical ROC values are unverified. I found no platoon paper that measured radar/lidar vs GNSS inter-vehicle distance in a REAL multi-vehicle field test with reported P_D/P_FA.

## Key question 6 — Which works explicitly consider a COORDINATED attacker that spoofs all members consistently, and what do they say about detectability? Any explicit "common translation is undetectable by relative checks" statement?

### Takeaway
Yes. Three sources state it explicitly: Park & Yoo (2026) formalise it as a gauge-freedom proposition (relative-only detectors are invariant under a common translation) and measure AUC ≈ 0.5 for the Mykytyn- and Bi-type detectors under a common slow ramp; Tibaldo et al. GNSS-WASP (USENIX Security 2025) demonstrate on hardware that a transmitter constellation keeps relative distances consistent and "prevents detection with classic multi-receiver countermeasures"; Chen, Dong & Duan (CCNC 2024, ICC 2025) prove a single spoofer makes all receivers read the same position (and can preserve formation for N ≤ 9). Among the detector papers, Mykytyn et al. (2023) acknowledge the per-UAV-consistent attack but dismiss it as "virtually impossible"; Bi et al. (2024) include "collusion" attacks; Heng et al. (2015) model peers spoofed by the same spoofer (P_SS) and need a positive reliability margin; Bhamidipati & Gao (2021) simulate "coordinated signal-level spoofing" of a receiver network but detect via temporal innovation bounds, not relative geometry.

### Cited Findings
- Explicit undetectability statement (formal): "a common, slowly varying translation of GNSS positions ... preserves all pairwise distances and is therefore unobservable to any relative-only detector (a gauge-freedom argument)"; Proposition 1: detectors depending only on {z_i − z_j} and {d_ij} are invariant under z_i ↦ z_i + c. Empirical: distance-verification AUC 0.56/0.49/0.48 and SDP-proxy AUC 0.54/0.49/0.48 at 2/5/20 cm/s common ramp. — [Park & Yoo, arXiv 2608.06885](https://arxiv.org/html/2608.06885)
- Explicit statement (experimental): GNSS-WASP spoofs "a swarm of victims to another location while preserving their true formation (i.e., their relative distances)"; "the relative distances across receivers remain consistent, preventing detection with classic multi-receiver countermeasures"; multi-receiver [Jansen et al. 2016] and sensor-fusion countermeasures "in their original form ... are ineffective at detecting GNSS-WASP within the 3D area where consistency is preserved". Remedy discussed: exploit the deterministic approximation error Δd_i with widely spaced receiver arrays (detection game, Sec. 5). — [Tibaldo et al., USENIX Sec 2025 pre-pub](https://www.usenix.org/system/files/conference/usenixsecurity25/sec25cycle1-prepub-757-tibaldo.pdf)
- Attack feasibility: a single spoofer makes "multiple receivers at different locations in a spoofing area ... see the same location reading" (formal analysis + SDR experiments). — [Chen, Dong, Duan, CCNC 2024](https://api.semanticscholar.org/graph/v1/paper/DOI:10.1109/CCNC51664.2024.10454872); formation-preserving swarm spoofing "GPS Swarm Spoofing: Theoretical Analysis and Practical Solutions", ICC 2025, DOI 10.1109/ICC52391.2025.11161002 — [Crossref](https://api.crossref.org/works?query.bibliographic=Chen+Dong+Duan+GPS+Swarm+Spoofing+Theoretical+Analysis+and+Practical+Solutions&rows=4)
- Detector authors' own position on the coordinated attacker: Mykytyn et al.: an attacker would need to "simultaneously spoof each GPS receiver of every drone in the swarm with an individual GPS [signal consistent] to the real-time distance between them, which is virtually impossible and very resource demanding" — i.e. acknowledged as the blind spot but judged impractical. — [arXiv 2301.12766](https://arxiv.org/pdf/2301.12766)
- Bi et al. consider "distributed, collusion, and mixed attack types" (colluding spoofed UAVs) and still report detection improvements, because collusion there means several malicious nodes reporting mutually consistent false positions while honest neighbours' ranges contradict them — not a translation of the WHOLE swarm. — [arXiv 2312.03787](https://arxiv.org/abs/2312.03787)
- Heng et al. explicitly model a cross-check peer "spoofed by the same spoofer" (probability P_SS) versus "by a different spoofer" (P_SD); the exponential bound P_FA = P_MD ≤ exp(−Nγ²) requires the margin γ (which decreases with P_SS) to be positive. — [Gao SCPNT 2014 slides](https://web.stanford.edu/group/scpnt/pnt/PNT14/2014_Presentation_Files/15.SCPNT_Coop%20Authentication_Gao_2014.pdf)
- Bhamidipati & Gao 2021 evaluate "a receiver network under coordinated signal-level spoofing" and detect via innovations leaving the p-Zonotope (temporal/bounded-error consistency) — [arXiv 2101.04835](https://arxiv.org/abs/2101.04835)
- Swaszek et al. 2017 explicitly restrict the attacker to a subset ("nominally one") vehicle — the complementary (all-vehicle) case is outside their model. — [ION abstract](https://www.ion.org/publications/abstract.cfm?articleID=15338)
- Crowd-GPS-Sec / Trust-the-Crowd handle attacks on "all sensors in a region" via fixed ground witnesses (Class A), and the 2021 paper needs ≥ 3 benign sensors. — [NDSS 2021 PDF](https://www.ndss-symposium.org/wp-content/uploads/2021-552-paper.pdf)

### Inferences
- Summary table of invariance (my classification):
  - Class R (blind to common translation; for distance-only ranging also to common rotation): Jansen-Tippenhauer-Pöpper 2016 fixed-baseline check; Mykytyn 2023; Bi 2024; Michieletto 2023 (spatial part); Meng 2023 (by construction, unverified); Eldosouky 2020; Swaszek 2017 platoon GLRT; Carson 2016 CACC; Kosmanos 2026 (spatial part).
  - Class A (anchored): Swaszek 2016 (ranges to fixed sites); Bhamidipati & Gao 2017/2019 (receivers at surveyed positions); Jansen 2018 Crowd-GPS-Sec and Jansen 2021 Trust the Crowd (fixed ground sensors); Krayani 2023 (RSU); Park & Yoo 2026 absolute-anchor residual (trusted anchor drones with an absolute reference).
  - Class S (signal-domain): Heng-Work-Gao 2015 (P(Y) cross-correlation — detects generator spoofing regardless of imposed geometry; peers must not all be under the same spoofer).
- Detectability of a consistent common offset therefore requires breaking the gauge: (i) an absolute anchor (fixed node, map/terrain, cellular/terrestrial ranging, celestial/magnetic heading for rotation), (ii) temporal consistency with inertial sensors (catches jumps/fast ramps, not slow drifts — Park & Yoo's floor v* = 2γ/(1 − t_s/T) quantifies the drift-limited case), or (iii) signal-domain checks (P(Y) correlation, AoA/TDOA of the spoofing emitter, residual Δd_i geometry errors of a transmitter constellation as in GNSS-WASP Sec. 5).

### Gaps
- No peer-reviewed (non-preprint) detector paper found that both (a) uses only inter-platform ranging and (b) explicitly proves the common-translation invariance; the formal statement exists only in the Park & Yoo arXiv preprint (Aug 2026) and, in attack-side form, in GNSS-WASP (USENIX 2025) and Chen et al. (2024/2025). Earlier works (Tippenhauer 2011) argue the inverse — that consistent group spoofing is hard with a single antenna — which the 2025–2026 papers overturn with multi-transmitter constellations.
