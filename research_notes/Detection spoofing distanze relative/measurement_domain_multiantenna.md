# Measurement-domain multi-antenna / multi-receiver GNSS spoofing detection exploiting known relative geometry (2009–2026)

Scope: civilian GNSS; detectors that use two or more antennas/receivers and test pseudorange or carrier-phase observables (single/double differences, DOA, baseline length, rigid-body range consistency, sum-of-squares) against the known relative geometry of the antennas. Position-domain multi-receiver tests are included only where needed for the invariant classification.

Notation used below (plain text): λ = carrier wavelength; D or b = baseline vector between antennas A and B, |b| its length; ρ̂_i (or u_i) = unit line-of-sight vector to satellite i; Δφ_i = single difference (SD) of carrier phase between antennas for satellite i; ∇Δφ_ij = double difference (DD) across antennas and satellites i,j; N = integer ambiguity; dT = receiver clock offset; H0/H1 as defined in each paper (note that several papers swap the roles: in Stenberg et al. H0 = "spoofed").

General invariant taxonomy used throughout:
- (I-DOA) direction-of-arrival consistency: the spread of inter-antenna phase (or DOA) across satellites must match the angular diversity expected from the satellite constellation; under single-transmitter spoofing all SDs collapse to one value (modulo ambiguities and clock).
- (I-RANGE) inter-antenna range consistency: differences of pseudoranges/carrier ranges between antennas must be consistent with the known baseline (length and/or vector).
- (I-POS) position-solution consistency: the distance (or vector) between the per-antenna position fixes must match the known baseline.
- "Relative" flag: whether the invariant is a purely relative quantity between antennas, so that a rigid translation of the whole array, with signals arriving at each antenna from the correct satellite directions (i.e., a spoofer able to synthesise per-antenna-consistent wavefronts), leaves it unchanged. For all three invariants the answer is YES when the attitude is unknown/estimated: the tests only check that the observables are consistent with SOME rigid placement of the array and the (spoofed) satellite geometry. They depend on absolute signal direction only when attitude is supplied externally (IMU, known heading) and compared against the ephemeris-predicted DOAs.

## KQ1. Psiaki et al. (Cornell/UT Austin): moving-antenna and two-antenna differential carrier-phase detectors; Psiaki & Humphreys 2016 survey

### Takeaway
The Cornell/UT family tests whether the beat-carrier-phase variations across antennas (or across a known single-antenna motion) are explained by a diverse set of satellite directions (non-spoofed) or by one common direction (spoofed), via a log-likelihood-ratio statistic γ = (cost of spoofed fit) − (cost of non-spoofed fit) with maximum-likelihood nuisance estimation (attitude/baseline direction, ambiguities, phase biases). The 2016 Proc. IEEE survey explicitly states that an "expensive" spoofer transmitting one spoofed signal per antenna from physically plausible directions "might deceive spoofing defenses that were based on signal direction of arrival".

### Cited Findings
- Psiaki, Powell, O'Hanlon, "GNSS Spoofing Detection Using High-Frequency Antenna Motion and Carrier-Phase Data", Proc. ION GNSS+ 2013, Nashville TN, pp. 2949–2991 (pages from the reference list of Psiaki & Humphreys 2016) — [UT RNL PDF of Psiaki & Humphreys 2016, ref. 12](https://rnl.ae.utexas.edu/images/stories/files/papers/gnss_spoofing_detection.pdf); abstract: beat carrier-phase from a single moving antenna; works for encrypted and civilian signals — [Cornell preprint](https://gps.mae.cornell.edu/Paper_F5_8_ION_GNSS_2013b.pdf) (server refused TLS/503 during this research; content from abstract and GPS World column).
- Companion GPS World "Innovation" column (June 2013): the beat carrier phase responds to known antenna motion through the projection of the motion onto each satellite's LOS unit vector; non-spoofed: different responses per satellite; spoofed: all responses identical ("carrier-phase sameness"). Multi-antenna model, eq. (4): λφ_i/2π = ρ_i0 + ρ̂_i^T Δd + c(δr − δ^i) + λβ_i/2π, Δd = antenna displacement from the nominal location; DOA ρ̂_i measurable by interferometry with ≥3 antennas with different Δd, or by a single antenna with known Δd(t); with 2 antennas (or 1-D motion) only one component of ρ̂_i is estimable; φ_i accuracy ≈ 1/40 cycle ⇒ ρ̂_i to ≈ 3° with a 0.1 m baseline; "A typical geometry-based spoofing detection system tests whether the received φ_i phases at the multiple antennas are more consistent with the diversity of ρ̂_i directions expected for authentic signals or with the uniformity of directions consistent with single-transmitter spoofing. The calculations for the non-spoofed hypothesis include an attitude determination algorithm" — same PDF.
- Multi-transmitter attacker in the same survey: "An advanced spoofer acting against a multi-antenna victim receiver might use multiple independent spoofer transmission antennas and match each one to a corresponding receiver antenna. The relative geometry of each spoofer/victim antenna pair would need to be known. Also, the spoofer would need to be sufficiently close to the victim and have sufficiently narrow individual antenna gain patterns so that each victim antenna received only the signal from the intended spoofer antenna … This type of spoofing would likely be practical only with a cooperative victim"; "An expensive type of multi-antenna spoofer might transmit only one spoofed signal from each antenna. Such a spoofer might deceive spoofing defenses that were based on signal direction of arrival. It might need to distribute its antennas about the victim so that the spoofed signal arrival directions would seem physically reasonable"; "A spoofer that transmits from multiple directions is harder to detect using such methods. If its directional diversity does not equate to that of the true set of ρ̂_i vectors, then it may be detectable. The research group that produced [8] (DLR) has developed a capability to detect such attacks" — same PDF.

### Inferences
- Invariant: I-DOA. Both the moving-antenna and the two-antenna detectors (attitude unknown, estimated under the non-spoofed hypothesis) are purely relative: a rigid translation of the array with per-antenna-correct wavefronts leaves γ unchanged. The two-antenna test with a 0.14 m baseline is essentially an attitude-determination residual test, so it is blind to a spoofer that reproduces the correct angular diversity (one transmitter per spoofed satellite direction) and, per the 2016 survey, to a per-receiver-antenna matched spoofer.
- Decision rule: LRT with ML nuisance estimation; thresholds set from worst-case P_FA by Monte Carlo rather than a closed-form chi-square (the cosine non-linearity and integer ambiguities prevent a simple closed form; see Rothmaier 2021 remark in KQ6).

### Gaps
- Exact ION GNSS+ 2014 page range and the explicit cost-function equations could not be read (Cornell server unreachable through the proxy); only the GPS World and Proc. IEEE descriptions were verified.

## KQ2. Montgomery, Humphreys, Ledvina (2009): differential carrier-phase, dual-antenna, common oscillator

### Takeaway
First experimental dual-antenna angle-of-arrival defence: L1 carrier-phase differences between two antennas sharing a common oscillator are compared with the diversity expected from the true constellation; the attack with a single portable spoofer was detected, but only abstract-level detail is verifiable online.

### Cited Findings

Ledvina, "Receiver-Autonomous Spoofing Detection: Experimental Results of a Multi-Antenna Receiver Defense against a Portable Civil GPS Spoofer", Proc. 2009 International Technical Meeting of The Institute of Navigation (ION ITM 2009), Anaheim, CA, Jan. 2009, pp. 124–130 (citation as given in Blanch et al. 2025 ref. [3]) — [Stanford ION GNSS+ 2025 PDF](https://web.stanford.edu/group/scpnt/gpslab/pubs/papers/blanch_ION_GNSS_2025_dual_antennas.pdf). A web-search summary noted one secondary source placing it in "Savannah, GA" — that is the ION GNSS 2008 venue and is inconsistent with ITM 2009 (Anaheim).

## KQ3. Borio & Gioia: Sum-of-Squares detector (TAES 2016), dual-antenna COTS system (ION GNSS+ 2015), and the alleged "Borio–Gioia 2022" paper

### Takeaway
The SoS detector (TAES 52(4):1756–1768, 2016) is a two-receiver, two-antenna carrier-phase detector derived in the GLRT framework: it uses the inter-receiver carrier-phase differences of all satellites, removes the common (clock/baseline-independent) term and tests whether the residual dispersion is consistent with a single arrival direction; it needs no common oscillator and makes no assumption on geometry (ION GNSS+ 2015 implementation). No 2022 Borio–Gioia multi-receiver paper could be found in Crossref, IEEE, ION, MDPI or JRC listings; the thesis's "Borio–Gioia 2022" citation appears to be erroneous.

### Cited Findings
- D. Borio, C. Gioia, "A Sum-of-Squares Approach to GNSS Spoofing Detection", IEEE Transactions on Aerospace and Electronic Systems, vol. 52, no. 4, pp. 1756–1768, Aug. 2016, DOI 10.1109/TAES.2016.150148 (Crossref-verified) — [Crossref](https://api.crossref.org/works/10.1109/TAES.2016.150148); JRC record JRC94954; abstract: "The SoS decision statistic is computed using carrier phase measurements from two spatially separated GNSS receivers and has a simple form suitable for real-time applications. The detector is theoretically characterized and its effectiveness is shown using simulations and experiments involving real GPS data" — [JRC repository](https://publications.jrc.ec.europa.eu/repository/handle/JRC94954).
- Signal model as summarised (and reused) by Rothmaier et al. 2021, who state their derivation "leverages the approximations justified in (Borio & Gioia, 2016) and equally considers the integer ambiguities as random variables": Δφ_i = (D/λ) cos α_i + ΔN_i + (c/λ)(dT2 − dT1) + Δη_i, with D = distance between phase centres, α_i = spatial angle between the baseline and the LOS of satellite i, ΔN_i integer, Δη ~ N(0, diag(σ_i^2)); "A procedure to characterize the σ_i's is given in (Borio & Gioia, 2016)"; under spoofing all α_i are equal; the double-difference vector Δ²φ = A Δφ (A = (N−1)×N differencing matrix) obeys H0: f(Δ²φ) = (D/λ) A cos α̂ + Δ²η/λ, H1 (spoofed): f(Δ²φ) = Δ²η/λ, with f(x) = x − round(x) (fractional part); Rothmaier adds: "No threshold computation guaranteeing a P_FAmax has been presented in the literature for this setup, nor is one possible with this paper's approach, due to the nonlinearity of the cosine function" when the attitude is unknown — [Rothmaier et al., NAVIGATION 2021, Sec. 2.6](https://navi.ion.org/content/navi/68/2/243.full.pdf).
- A secondary source describes the SoS detector as "derived with a generalized likelihood ratio test" and reports a later "dispersion of double difference measurements" (D³) dual-antenna detector as an improvement over SoS — [search summary citing ResearchGate records](https://www.researchgate.net/publication/331205537_A_Dual_Antenna_GNSS_Spoofing_Detector_Based_on_the_Dispersion_of_Double_Difference_Measurements) (authors/venue of the D³ paper: unverified).
- Blanch et al. (ION GNSS+ 2025) cite Borio & Gioia 2016 as the reference for "not detecting a complete capture" tests and note "It is much harder to design tests that will detect partial capture and to ensure that the probability of false alert is not excessive" — [Stanford PDF](https://web.stanford.edu/group/scpnt/gpslab/pubs/papers/blanch_ION_GNSS_2025_dual_antennas.pdf).
- D. Borio, C. Gioia, "A Dual-antenna Spoofing Detection System Using GNSS Commercial Receivers", Proc. 28th International Technical Meeting of the Satellite Division of The Institute of Navigation (ION GNSS+ 2015), Tampa, FL, Sept. 14–18, 2015, pp. 325–330 (no DOI; ION assigned DOIs only from 2016) — [ION abstract](https://www.ion.org/publications/abstract.cfm?articleID=12854); abstract: "a new class of spoofing detectors, based on the availability of carrier phase measurements from two separate antennas … implemented on a real-time platform using two COTS GPS receivers … the approach is general and does not make any assumption on the system geometry … the two receivers operate independently without a shared oscillator"; a software platform parses the receivers' binary messages and computes the decision statistic in real time; "several tests" show it to be an effective low-cost solution (no quantitative figures in the abstract) — [JRC94730](https://publications.jrc.ec.europa.eu/repository/handle/JRC94730).
- Related Borio single-receiver precursor: D. Borio, "PANOVA Tests and their Application to GNSS Spoofing Detection", IEEE TAES, vol. 49, no. 1, pp. 381–394, 2013 (phase-only ANOVA: tests whether sample groups have means with different phases, applied to characterise the spatial signature of signals) — [search summary](https://www.jseepub.com/EN/Y2024/V35/I5/1276).
- Crossref title search for "dual-antenna spoofing detection system Borio Gioia" returns only TAES 2016 and "Real-time jamming detection using the sum-of-squares paradigm" (ICL-GNSS 2015, DOI 10.1109/ICL-GNSS.2015.7217161) — [Crossref query result in this research]. Web search for "Borio Gioia 2022 multi-receiver spoofing detection" returned no such paper; the closest 2022 multi-receiver items are Stenberg et al. (NAVIGATION 2022) and Pardhasaradhi et al. (IEEE Access 2022), neither by Borio/Gioia — [search results](https://archive.cps-vo.org/node/35536).

### Inferences
- Observable/statistic: SD of carrier phase between two independent receivers; the inter-receiver clock term is common to all satellites and is removed by double differencing (or equivalently by subtracting the mean), leaving fractional-cycle DDs that are ~0 (noise only) under single-transmitter spoofing and spread (depending on D cos α_i / λ) otherwise; the "sum of squares" is the energy of these residuals; detection declares spoofing when the SoS is SMALL (the spoofed hypothesis is the "simple" one), threshold from the central chi-square-like distribution of the noise-only residuals (exact degrees of freedom and scaling: unverified from the primary text).
- Attacker model: single transmitter (all signals from the same direction). Assumptions: no common oscillator needed; integer ambiguities treated as random/fractional parts used; the baseline need not be known (geometry-free), which also means the test cannot exploit |b|; longer D increases the separation between hypotheses.
- Invariant I-DOA, purely relative (no attitude, no baseline knowledge used): a multi-transmitter spoofer reproducing angular diversity, or a rigid translation with correct wavefronts, is undetectable by construction.
- "Borio–Gioia 2022": most probably a mis-citation; candidates for what the thesis intended are Borio & Gioia TAES 2016 (SoS), Borio & Gioia ION GNSS+ 2015 (dual-antenna COTS), or a non-Borio 2022 multi-receiver paper (Stenberg et al. 2022; Pardhasaradhi et al. 2022). The report should say explicitly that no 2022 Borio–Gioia multi-receiver paper was found.

### Gaps
- The TAES 2016 full text (exact SoS formula, chi-square degrees of freedom, P_FA/P_D curves, real-data results) was not accessible (IEEE Xplore and ResearchGate blocked; JRC provides no open PDF). Mark the statistic details above as reconstructed from secondary sources.

## KQ4. "Lee, Kim, Lee et al., EURASIP JASP 2020, DOI 10.1186/s13634-020-0663-z": rigid-body multi-receiver statistical test

### Takeaway
The DOI 10.1186/s13634-020-0663-z belongs to A. Kalantari and E. G. Larsson (Linköping University), not to "Lee, Kim, Lee": "Statistical test for GNSS spoofing attack detection by using multiple receivers on a rigid body", EURASIP J. Adv. Signal Process. 2020:5 (vol. 2020, art. no. 5), 26 Feb 2020, CC-BY. It is a GLRT consistency check of range measurements from N receivers with known relative positions on a rigid platform of unknown position/orientation, explicitly designed for MULTIPLE spoofers; more receivers increase detectability and restrict the spoofers' optimal positions.

### Cited Findings
- Bibliographic data (Crossref): title "Statistical test for GNSS spoofing attack detection by using multiple receivers on a rigid body"; authors Ashkan Kalantari, Erik G. Larsson; EURASIP Journal on Advances in Signal Processing, vol. 2020, issue 1 (article 5), published 2020-02-26; licence CC-BY 4.0 — [Crossref](https://api.crossref.org/works/10.1186/s13634-020-0663-z); open access at [SpringerOpen](https://asp-eurasipjournals.springeropen.com/articles/10.1186/s13634-020-0663-z).
- Abstract (Crossref copy): "This paper proposes a new statistical test for the presence of multiple spoofers based on range measurements observed by a plurality of receivers located on a rigid body platform. The relative positions of the receivers are known, but the location and orientation of the platform are unknown. The test is based on the generalized likelihood ratio test (GLRT) paradigm and essentially performs a consistency check between the set of observed range measurements and known information about the satellite topology and the geometry of the receiver constellation. Optimal spoofing locations and optimal artificial time delays (as induced by the spoofers) are also determined. Exact evaluation of the GLRT requires the maximum-likelihood estimates of all parameters, which proves difficult. Instead, approximations based on iterative algorithms and the squared-range least squares algorithm are derived. The accuracy of these approximations is benchmarked against Cramér-Rao lower bounds. Numerical examples demonstrate the effectiveness of the proposed algorithm and show that increasing the number of GNSS receivers makes the attack easier to detect. We also show that using multiple GNSS receivers limits the availability of optimal attack positions" — same Crossref record.
- Introduction statement (search snippet of the full text): methods that rely on correlated spoofer signals (all receivers reporting the same position / same direction) can fail because "attacks using multiple spoofers can result in spatially uncorrelated spoofing signals, in which case these methods can fail" — [search summary of the full text](https://asp-eurasipjournals.springeropen.com/track/pdf/10.1186/s13634-020-0663-z).
- The analysis uses a two-dimensional model, with the extension to 3-D left for future work; figure captions report detection probability versus false-alarm probability for "N = I = 3" and "N = 5, I = 3" (N and I are the receiver and spoofer counts in the paper's notation; mapping unverified) — [search summaries](https://asp-eurasipjournals.springeropen.com/articles/10.1186/s13634-020-0663-z/figures/8).
- Related Linköping works on multiple spoofers (same group): Z. Gulgun, E. G. Larsson, P. Papadimitratos, "Multiple Spoofer Detection for Mobile GNSS Receivers Using Statistical Tests", IEEE Access, vol. 9, pp. 166382–166394, 2021, DOI 10.1109/ACCESS.2021.3135517; Z. Gulgun, E. G. Larsson, P. Papadimitratos, "Statistical Method for Spoofing Detection at Mobile GNSS Receivers", ISWCS 2019, pp. 677–681, DOI 10.1109/ISWCS.2019.8877106 — [Crossref queries in this research].
- Earlier multi-receiver GLRT works by Larsson/Axell: E. Axell, E. G. Larsson, D. Persson, "GNSS spoofing detection using multiple mobile COTS receivers", ICASSP 2015, pp. 3192–3196, DOI 10.1109/ICASSP.2015.7178560; E. Axell, M. Alexandersson, T. Lindgren, "Results on GNSS meaconing detection with multiple COTS receivers", ICL-GNSS 2015, pp. 1–6, DOI 10.1109/ICL-GNSS.2015.7217162 (pseudorange DD plus position differences, joint decision whether all receivers are spoofed) — [Crossref] and [Stenberg et al. 2022 ref. list](https://navi.ion.org/content/navi/69/1/navi.510.full-text.pdf).

### Inferences
- Observable: pseudoranges/ranges r_{n,k} from receiver n to (true or spoofed) source k; H0 (no spoofing): r_{n,k} = |p + R q_n − s_k| + c dt + noise with known satellite positions s_k, known body-frame offsets q_n, unknown platform position p and rotation R; H1: some ranges originate from I spoofers at unknown positions with artificial delays. GLRT = ratio of maximised likelihoods; since ML under the non-linear model is hard, the authors use iterative solvers and squared-range least squares (SR-LS) estimates; the test is a chi-square-type residual consistency test with threshold set for a target P_FA (exact threshold expression: unverified).
- Invariant I-RANGE (rigid-body range consistency), purely relative: the test is invariant to any rigid translation/rotation of the body as long as the ranges at each receiver are consistent with that placement. The paper itself frames the detectable case as spoofers that cannot make all N receivers' ranges simultaneously consistent; with I spoofers at optimal positions the attack is harder to detect, and more receivers shrink the set of such positions. This is the paper that most directly addresses the "one transmitter per receiver / multiple distributed transmitters" attacker model.
- The thesis's author attribution ("Lee, Kim, Lee") must be corrected.

### Gaps
- Full text (equations of the GLRT, SR-LS approximation, CRLB, numerical P_D values, simulation parameters such as baseline sizes and noise σ) could not be downloaded (Springer blocked the proxy); the report should cite the abstract-level claims only.

## KQ5. DLR antenna-array / DOA detectors (Meurer, Konovaltsev, Cuntz, Hättich, Appel; 2012–2019)

### Takeaway
The DLR line compares array-measured DOAs with ephemeris/almanac-predicted DOAs through a Wahba-type attitude fit; the residual SSE = trace{[R D_enu − D_loc]^T R_N^{-1} [R D_enu − D_loc]} is central chi-square with 2N_DOA − 3 d.o.f. under consistency and non-central chi-square with λ = Σ(Δ_n/σ_n)^2 otherwise; detection/exclusion runs as a multiple-hypothesis RAIM over DOA subsets, validated against a meaconing repeater (static and dynamic) and later at sea (CEAS Space J. 2019, normalised-singular-value metric with an empirically chosen threshold 0.985).

### Cited Findings

## KQ6. Stenberg et al. NAVIGATION 2022 (measurement-domain part) and the closely related double-difference GLRT literature

### Takeaway
Stenberg, Axell, Rantakokko, Hendeby test each pseudorange or carrier-phase double difference ∇Δ_{ij}^{kl}[n] (receivers i,j; satellites k,l) with a linear-model GLRT (chi-square with r = 2 d.o.f. for pseudorange and r = 1 for carrier phase when σ² is known; F-distribution when unknown), declare a measurement spoofed when it belongs to ≥ K−1 = 3 "all-spoofed" double differences (single-transmit-antenna assumption, K = 4), and report that pseudorange DDs work for receiver separations ≥ 5 m (6/7 signals authenticated within 30 s at 20 m), while carrier-phase DDs allow shorter baselines but needed empirical thresholds because of inter-receiver time-synchronisation errors.

### Inferences
- Stenberg/Axell/Wang/Wen: invariant I-RANGE (pseudorange DD across receivers ≈ projection of the baseline on the LOS difference; under single-source spoofing DD → 0 because both receivers see the same wavefront). Purely relative; the single-transmit-antenna assumption is explicit (K parameter). A spoofer with one transmitter per receiver, each synthesising the correct ranges for that receiver's location, would produce non-zero, geometry-consistent DDs and pass. - Blanch et al.: invariant I-RANGE with the baseline LENGTH known (|v| = d) and orientation estimated; relative; first work giving protection levels (worst-case non-centrality per capture hypothesis).

Arizabaleta (UniBw München), ION ITM 2024, Long Beach: double-differenced phase discriminator values from a dual-antenna receiver give "an almost instant indication of an attack but need statistical verification", OSNMA has ≥ 30 s latency; the combination yields fast and reliable identification (full citation unverified) — [UniBw news](https://unibw.de/lrt9/lrt-9.2/aktuelles/on-the-synergy-between-galileo-open-service-message-authentication-osnma-and-dual-antenna-receivers-to-detect-gnss-spoofing-presented-by-markel-arizabaleta-at-the-ion-itm-2024-in-long-beach-california).

### Inferences
- Hu 2018, Chen 2020, Chen 2024: invariant I-DOA, relative (no attitude needed; Chen 2024 uses the known collinear geometry and baseline lengths but still only checks internal consistency of the pointing vector). Zhang 2024: I-DOA with ABSOLUTE direction (IMU attitude + ephemeris), so a rigid translation does not matter but a mismatch of DOA with the ephemeris does; this is the only recent dual-antenna work that would also flag a multi-transmitter spoofer whose transmitters are not placed along the true satellite directions.
- Pardhasaradhi 2022 and Chen 2023: invariant I-POS (plus clock-offset single differences), relative; explicitly single-station attacker.
- None of the 2018–2026 UAV/vehicle papers found treats a spoofer with one transmitter per receiver; this remains the open case addressed analytically only by Kalantari & Larsson 2020 (ranges) and qualitatively by Psiaki & Humphreys 2016.

### Gaps
- No dedicated UAV-flight dual-antenna spoofing-detection journal paper with full statistics was found in this search (UAV appears as motivation in Electronics 2024/Remote Sensing 2024; a 2024 TrustCom UAV paper "AttDet" uses attitude plus machine learning and no extra antennas).

## KQ8. Which papers address MULTIPLE spatially distributed transmitters, and what do they conclude?

### Takeaway
Only Psiaki & Humphreys 2016 (qualitative), Kalantari & Larsson 2020 (analytical, rigid-body ranges), Rothmaier et al. 2021 and Esswein & Psiaki 2019/2025 (hypothesis search over spoofer subsets) treat multi-transmitter attackers; the consensus is that a per-victim-antenna matched spoofer or a one-transmitter-per-satellite spoofer with physically plausible directions defeats DOA/relative-geometry tests, that such attacks are costly and "likely practical only with a cooperative victim", and that increasing the number of receivers/antennas shrinks the attacker's feasible configurations without eliminating them.

### Cited Findings
- Psiaki & Humphreys 2016: multi-transmitter spoofer matched to each victim antenna requires known relative geometry, proximity and narrow beams, "practical only with a cooperative victim"; one-signal-per-antenna spoofer "might deceive spoofing defenses that were based on signal direction of arrival"; a spoofer from multiple directions "may be detectable" if its directional diversity differs from the true ρ̂_i set; the attack/defence matrix (Table I, 13 detection techniques) notes that "A number of these defenses will remain vulnerable to a determined spoofer with a very large budget" — [UT RNL PDF](https://rnl.ae.utexas.edu/images/stories/files/papers/gnss_spoofing_detection.pdf).
- Psiaki et al. 2013 (moving antenna) and 2014 (two antennas) both list multi-location/multi-antenna spoofers as untested future work — [GPS World 2013](https://www.gpsworld.com/innovation-gnss-spoofing-detection-correlating-carrier-phase-with-rapid-antenna-motion/); [GPS World 2014](https://www.gpsworld.com/gnss-lies-gnss-truth/).
- Kalantari & Larsson 2020: test designed "for the presence of multiple spoofers"; "attacks using multiple spoofers can result in spatially uncorrelated spoofing signals, in which case these methods [correlation-based multi-receiver tests] can fail"; "increasing the number of GNSS receivers makes the attack easier to detect … using multiple GNSS receivers limits the availability of optimal attack positions"; optimal spoofer locations and artificial delays are derived — [Crossref abstract](https://api.crossref.org/works/10.1186/s13634-020-0663-z).
- Rothmaier et al. 2021: acknowledges multi-antenna transmitters ("difficult to mount, it is possible – especially for the case of a cooperative victim"), handles multiple sources only through iterative subset testing; "closely spaced spoofed satellites are hard to detect"; cites Esswein & Psiaki 2019 for an exhaustive (1 + S)^N hypothesis search — [NAVIGATION 68(2)](https://navi.ion.org/content/navi/68/2/243.full.pdf).
- Stenberg et al. 2022: single transmit antenna is "a key assumption"; the K = 4 grouping rule follows from it — [NAVIGATION 69(1)](https://navi.ion.org/content/navi/69/1/navi.510.full-text.pdf).
- Hu et al. 2018, Chen et al. 2024, Chen et al. 2023 abstracts: all condition on "one single antenna"/"single-station" spoofing — [Crossref abstracts above].
- Blanch et al. 2025: multi-antenna methods "have shown very good results, at least against single emitter spoofing"; dependence on antenna geometry, noise and the set of effectively spoofed signals has received "much less attention"; partial-capture detection is "much harder" — [Stanford PDF](https://web.stanford.edu/group/scpnt/gpslab/pubs/papers/blanch_ION_GNSS_2025_dual_antennas.pdf).

### Inferences
- Classification summary (method → invariant → relative?):
  - Montgomery 2009; Psiaki 2013/2014; Borio–Gioia 2015/2016; Hu 2018; Chen 2020; Chen (Electronics) 2024; Rothmaier 2021 (array, unknown attitude) → I-DOA → relative (array attitude free).
  - Rothmaier 2021 two-antenna variant; Zhang (Remote Sensing) 2024; DLR 2012–2019 when attitude is externally known → I-DOA → depends on absolute direction (ephemeris comparison); with attitude estimated jointly (DLR default) → relative up to a rotation.
  - Axell 2015; Jahromi 2016; Wang 2018; Wen 2019; Stenberg 2020/2022; Blanch 2025; Kalantari–Larsson 2020 → I-RANGE → relative (rigid translation/rotation invariant; only inconsistency with SOME placement is detectable).
  - Swaszek–Hartnett 2013/2014; Radin 2015; Jansen 2016; Pardhasaradhi 2022; Chen 2023 → I-POS → relative.
- Consequence for a distributed (one-transmitter-per-receiver, or one-per-satellite-direction) attacker: every relative invariant above is satisfiable in principle by an attacker who knows the victim's antenna layout and can deliver antenna-specific signals (narrow beams, proximity) or reproduce the true angular diversity; the literature's defence is cost (Psiaki & Humphreys), geometric infeasibility growing with the number of receivers (Kalantari & Larsson), and the absolute-direction check against ephemeris with an independent attitude sensor (DLR/Zhang 2024), which forces the attacker's transmitters onto the true satellite directions.

### Gaps
- No paper found that experimentally demonstrates a multi-transmitter attack against a multi-antenna detector; all experimental validations (yacht 2014, DLR balloon/ship, Stenberg live-sky, Jammertest 2024) use a single emitter or repeater.
- Esswein & Psiaki 2019/2025 contents (how many spoofer antennas S, detection performance) were not read.
